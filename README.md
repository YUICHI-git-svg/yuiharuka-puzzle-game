# ゆいとはるかのパズルゲーム

結衣と遥のためのパズルバトルゲーム（PWA）。ホーム画面に追加するとアプリのように全画面で遊べます。セーブデータは端末の localStorage に保存されます。

## ファイル一覧

- `index.html` — ゲーム本体（単一ファイル）
- `manifest.webmanifest` — PWA マニフェスト
- `sw.js` — Service Worker（オフライン用キャッシュ）
- `icon-192.png` / `icon-512.png` — アプリアイコン
- `dragon-fire.png` — ほのおドラゴン
- `dragon-water.png` — みずドラゴン
- `dragon-forest.png` — もりドラゴン
- `fairy-flower.png` — はなのようせい
- `fairy-star.png` — ほしのようせい
- `phoenix.png` — ひのとり（フェニックス）

## 公開先

- リポジトリ名: `yuiharuka-puzzle-game`（GitHub Pages で公開予定）
